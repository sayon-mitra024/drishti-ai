Ethical Governance & Regulatory Declarations

verified_user Clinical Decision Support Tool

Drishti AI is designed as a clinical decision support tool to aid trained healthcare practitioners. It is not an autonomous diagnostic agent. Model predictions must be validated by licensed ophthalmic clinicians prior to therapeutic intervention or referrals.

Intended Operator: Ophthalmologist, Optometrist, Resident
lock Local Memory Privacy Protocol

Retinal images are processed according to deployment environment privacy standards. No unencrypted patient identifiers leave local memory. Inference passes run completely sandboxed inside the client workstation runtime container.
